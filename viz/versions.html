Rubik RL: model versions

Every trained model: its training scheme, the features it uses, and its results. Lengths are in HTM moves. Last updated 2026-11-24 (after r3.11.0 finished).

Version labels: rMAJOR.MINOR.PATCH
MAJOR a big change in performance
MINOR a change to the training scheme or settings
PATCH a bug fix

The run names in brackets (for example exact_v1) are the folder names in checkpoints/ and runs/train/.

Shortest solutions on random cubes (random_1000, 50 cubes, best search per version)

Shorter is better. Each bar is drawn as 40 minus the length, so a longer bar means a shorter solution. The solve rate is in brackets; lengths are averaged over solved cubes only. Grey bars are the reference solver: Kociemba's two-phase algorithm, someone else's work, used only as a benchmark.
